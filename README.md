# MIDIGuard

MIDIGuard is a Python application that combines MIDI file analysis,
music theory, and defensive cybersecurity.

## Project Goals

- Analyze MIDI files and extract musical information.
- Identify notes, instruments, chords, scales, and keys.
- Detect malformed MIDI structures and unusual events.
- Inspect metadata and potential file integrity issues.
- Eventually provide a user-friendly interface.

## Technologies

- Python
- Mido
- music21
- pytest
- Flask
- Git and GitHub
